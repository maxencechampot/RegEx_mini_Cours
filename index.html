Data Science — outil essentiel

Les expressions
régulières

Une RegEx (Regular Expression) est un langage de motifs permettant de décrire, rechercher, extraire et transformer des structures de texte. Comme un scalpel pour la donnée brute : on définit la forme exacte de ce qu'on cherche — un email, une date, un code postal — et la RegEx le trouve, partout, instantanément.

01 — Pourquoi l'utiliser

La puissance des RegEx

⛏

Extraction

Extraire emails, URLs, montants, dates d'un corpus de texte brut en une ligne

✓

Validation

Vérifier qu'un champ respecte un format précis avant de traiter la donnée

🧹

Nettoyage

Supprimer ou remplacer des patterns indésirables dans vos DataFrames

⇄

Transformation

Standardiser des formats : dates, codes, numéros de téléphone

🔎

Parsing

Analyser des logs serveur, des fichiers CSV malformés, du HTML brut

02 — Apprendre la syntaxe

Les caractères fondamentaux

Caractères spéciaux

.N'importe quel caractère (sauf newline)
\dUn chiffre — équivalent à [0-9]
\wAlphanumérique + underscore
\sEspace, tabulation, newline
^Début de chaîne
$Fin de chaîne
[abc]a, b ou c — classe de caractères
|OU logique entre motifs

Quantificateurs

*0 ou plusieurs fois
+1 ou plusieurs fois (au moins une)
?0 ou 1 fois (élément optionnel)
{3}Exactement 3 répétitions
{2,5}Entre 2 et 5 répétitions
{3,}Au moins 3 répétitions
(...)Groupe de capture nommé
\Échappe un caractère spécial

04 — Cas concrets

Exemples Python data science

Extraction d'emails

import re
texte = "Contact: alice@gmail.com ou bob@corp.fr"
emails = re.findall(r'[\w.-]+@[\w.-]+\.\w+', texte)
# → ['alice@gmail.com', 'bob@corp.fr']
Résultat : ['alice@gmail.com', 'bob@corp.fr']

Extraction de dates

doc = "Rapport du 12/03/2024 et du 05/11/2023"
dates = re.findall(r'\d{2}/\d{2}/\d{4}', doc)
# → ['12/03/2024', '05/11/2023']
Résultat : ['12/03/2024', '05/11/2023']

Nettoyage de données (pandas)

import pandas as pd
df['prix'] = df['prix'].str.replace(r'[€\s,]', '', regex=True)
# "1 299,00 €" → "129900"
Nettoie les montants avant conversion numérique

Validation de numéro de téléphone FR

pattern = r'^0[1-9](\d{2}){4}$'
numeros = ["0612345678", "06-12-34", "0145678901"]
valides = [n for n in numeros if re.match(pattern, n)]
# → ['0612345678', '0145678901']
Résultat : ['0612345678', '0145678901']

Parsing de logs serveur

log = '192.168.1.1 - - [12/Mar/2024] "GET /api 200 512"'
m = re.search(r'(\d+\.\d+\.\d+\.\d+).*"(\w+)\s(\S+)\s(\d{3})', log)
ip, methode, route, code = m.groups()
# → '192.168.1.1', 'GET', '/api', '200'
Extrait IP, méthode, route et code HTTP en une RegEx
